# CLEAN DM — sitio existente

Fuente de mantenimiento del sitio publicado en https://cleandmlimpieza.com.ar/.
El 11/10/2026 se incorporó al repositorio la versión vigente del cliente, que no tenía una copia local. El contenido, CSS, JavaScript y las ocho imágenes previas se conservaron.

El pedido de Erickson, confirmado por el usuario, agrega el cartel de retiro de residuos. La pieza original se conserva sin cambios en `images/retiro-residuos.png` (1024×1536). La sección nueva usa `residuos.css`, muestra la imagen completa y permite consultar por WhatsApp al número del cartel, coincidente con el de la web: 5491162152800.

Se agregó una portada propia de 1200×630 en `images/og-residuos.jpg`, se ajustó la descripción y se completaron og:site_name, og:locale y JSON-LD con datos ya presentes en la web y el cartel. Los demás datos comerciales pertenecen al sitio recibido; este mantenimiento no constituye una nueva auditoría de esos datos.

El archivo de despliegue y los respaldos se guardan fuera del repositorio. Publicar únicamente index.html, residuos.css, images/retiro-residuos.png e images/og-residuos.jpg; no reemplazar otros archivos del cliente.
